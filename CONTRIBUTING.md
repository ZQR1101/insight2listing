# Contributing

The project is currently in the design and scaffolding phase.

Before implementing a feature:

1. Check the product and technical specification.
2. Keep source code, datasets, images, and third-party assets under separate licenses.
3. Do not add scraped Amazon content or credentials to the repository.
4. Add tests and update the relevant schema or documentation when behavior changes.
5. Preserve bilingual user-facing text where a feature is exposed in the UI.
