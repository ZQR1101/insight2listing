# Insight2Listing Web

Workflow-first Next.js interface for Insight2Listing.

## Development

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.

## UI direction

- shadcn-style source-owned primitives
- restrained Kokonut-inspired composition and micro-interactions
- evidence and workflow state before decorative analytics
- bilingual UI from the first screen
- accessible Radix primitives for layered interactions
